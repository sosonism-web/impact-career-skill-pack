# 커리어 확장 매핑 기준 프레임워크 (Career Expansion Mapping Framework)

AI 멘토가 사용자의 인터뷰 답변을 분석하여 **[Page 2: 미래지향적 커리어 확장 로드맵]**을 도출할 때 사용하는 핵심 참조 데이터입니다.

---

## 1. 직무 호환성 및 인접 산업 매트릭스 (Market Crossover Map)

임팩트 현장의 언어를 일반 채용 시장(원티드, 링크드인 표준 직무 분류 및 EU ESCO 전이 역량 기준)의 고부가가치 직무 및 인접 산업으로 번역합니다.

| 현장 경험 유형 | 호환 가능한 시장 직무 (Market Role) | 연결 가능한 인접 산업군 (Adjacent Industries) |
| :--- | :--- | :--- |
| **이해관계자 설득 및 지역/기관 협력**<br>(지자체, 기업, 주민 등 다자간 조율) | • B2B / B2G 사업개발 (Business Development)<br>• 전략 파트너십 매니저 (Strategic Partnership)<br>• 대외협력 (GR) / 얼라이언스 PM | • 대기업 ESG 추진실 / 임팩트 투자사<br>• 프롭테크 / 로컬 크리에이터 플랫폼<br>• 플랫폼 기업 제휴·신사업팀 |
| **현장 밀착 운영 및 프로그램 개선**<br>(참여자 모집, 커뮤니티 운영, 피드백 반영) | • 프로그램 / 프로덕트 오너 (PO / PM)<br>• 고객경험(CX) / CRM 기획 매니저<br>• 커뮤니티 빌더 / UX 리서처 | • 에듀테크 / 커리어·HRD 플랫폼<br>• 조직문화 컨설팅 / 코워킹 스페이스<br>• 라이프스타일·커머스 커뮤니티 |
| **성과 기록·사례 아카이빙·콘텐츠 확산**<br>(결과보고서, 임팩트 리포트, 인터뷰집 제작) | • B2B 브랜드 마케터 / 콘텐츠 전략 PM<br>• ESG 공시·지속가능경영 리포팅 매니저<br>• PR / 기업 커뮤니케이션 매니저 | • B2B SaaS / 미디어·콘텐츠 스타트업<br>• 기업 CSR·브랜딩실<br>• 리서치 기관 / ESG 컨설팅펌 |
| **창업팀 발굴·육성 및 자원 연결**<br>(멘토링, 데모데이, 투자자·대기업 매칭) | • 오픈이노베이션 프로그램 매니저<br>• 액셀러레이터(AC) / VC 밸류업 매니저<br>• 신사업 기획 / 전략기획 | • 대기업 CVC / 오픈이노베이션 센터<br>• 스타트업 생태계 지원 플랫폼<br>• 벤처캐피탈(VC) / 기업 육성 기관 |

## 2. 내년의 스케일업 도전 과제 도출 공식 (Next Project Idea)

사용자의 올해 성취 단계에 맞춰 내년에 현 조직에서 먼저 제안해 볼 수 있는 '한 단계 높은 수준'의 프로젝트를 설계합니다.

1. **[실행 ➔ 시스템화 (Playbook)]**: 올해 맨땅에 헤딩하며 첫 사례를 성사시켰다면 ➔ 내년에는 누가 와도 재현할 수 있는 **'표준 운영 플레이북/매뉴얼 구축 및 리드타임 단축'**을 도전 과제로 제안합니다.
2. **[단발성 ➔ 지속가능 수익/파트너십 모델]**: 올해 일회성 기금이나 보조금으로 운영했다면 ➔ 내년에는 **'기업 스폰서십 패키지 결합(B2B 세일즈) 또는 상시/유료화 전환 모델 기획'**을 제안합니다.
3. **[정성적 반응 ➔ 임팩트 데이터화]**: 올해 현장의 정성적 호응을 확인했다면 ➔ 내년에는 **'참여자 전후 변화 측정 지표(Impact KPI) 설계 및 리텐션 데이터 대시보드 구축'**을 제안합니다.

## 3. 몸값을 높이는 실무 증거물(Evidence) & 시너지 역량 추천

1. **갈무리해야 할 핵심 증거물 (Open Badge / Portfolio Evidence)**:
   - 거창한 결과 수치 대신 **'문제를 정의하고 설득한 과정이 담긴 산출물'**을 콕 집어 추천합니다.
   - *예시*: 이해관계자 설득용 첫 제안서 초안, 현장 문제를 재정의한 기획 노트, 참여자 이탈을 막기 위해 만든 운영 체크리스트, 파트너사 피드백 원문 아카이브 등.
2. **시너지 역량 (Skill-up 1 Spoon)**:
   - 현장의 정성적 강점에 결합했을 때 시장 가치가 급상승하는 실무 무기 1가지를 추천합니다.
   - *예시*: 노코드 자동화(Zapier/Make/Notion DB), 데이터 리터러시(GA4/설문 퍼널 설계), B2B 콜드메일 및 제안서 프레임워크, 글로벌 임팩트 측정 기준(IMP/GRI 기초) 등.
